## Notes

- Both ZIPs bundle the pre-repair `features.py` (no `load_tokenizer`), so their
  DeepSeek features use the whitespace-stripping `LlamaTokenizer` — what the grader
  would do. The dump uses the repaired tokenizer.
- v3b splits each batch at its median margin, so it predicts ~half robust per model
  (16/34 labelled, 18/37 overall) while 24/34 labels are robust; Skywork has only 3 rows.
- 34 labelled rows: one row flips accuracy by 0.029.
