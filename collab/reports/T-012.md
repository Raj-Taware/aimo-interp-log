## Observations

Not blockers; nothing was changed:

1. **Qwen3.5-4B attnx layer indexing.** `profile__distract__attnx` is finite only at
   hidden-state indices 1–8 of 33. Qwen3.5-4B's eager forward appears to return
   attention tensors only for its 8 full-attention layers, and `_attention_excess`
   numbers them 1..8 via `enumerate`. If that is right, the values come from blocks
   4, 8, …, 32 but are stored at depths 1–8, so `distract_attnx_d0.1/d0.25` are
   mislabelled and d0.4+ are NaN. `distract_attnx_mean` (mean over the 8) is finite.
2. **Skywork final layer.** For all 3 cases the final hidden-state layer (index 28) gives
   NaN cka/wcos/ans, and attnx at index 28 is NaN, while the last-token logit-lens KL
   is finite. That looks like fp16 non-finite values at some non-final token positions
   in the last block, which poison the per-layer mean/std.
