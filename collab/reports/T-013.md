## Observations

Not blockers; nothing was changed:

1. **Qwen3.5 attnx d-columns** now come from the nearest layer that has attention
   (`_sample_nearest`), e.g. d0.1 → index 4. Up to 0.56 different from T-012's mislabelled
   values.
2. **Skywork last-layer attention is still NaN.** `profile__distract__attnx` at index 28 is
   NaN in 3/3 cases (finite 1–27). The hidden-state fix covers cka/wcos/ans, not the
   attention tensor. Effects: `distract_attnx_d1.0` is now finite, but via nearest-finite
   it is index 27's value, not 28's. `distract_attnx_mean` went from finite in T-012
   (`nanmean` over the profile) to **NaN in all 3 cases**, because the new mean is
   `np.mean` over the per-layer values, NaN one included. This is a regression for Skywork.
   Other models are unaffected (their attention has no NaN).
