# T-003 — Failure-type specificity (pre-registered, CPU only)

**Why.** If the multi-distractor features measure *distractibility*, they
should predict failures under **distract** perturbations better than failures
under other types. Specificity is evidence of mechanism, not just of a
generic difficulty signal. This hypothesis is fixed **before** looking at
results; report every cell, including ones that go the other way.

**Pre-registered hypothesis.** Among the types, AUC is highest for `distract`.

**Inputs.**
- features + labels: `self-perturb/results/feature-dumps/2026-09-29_v3-features_tf5.13_unbatched-fp16/deepseek-ai_DeepSeek-R1-0528-Qwen3-8B.npz`
- per-type decay: `math-robust-final.csv` (https://github.com/aimo-interp/baselines, `data/`)

**Definitions.**
- Per problem and type X present in the CSV: `failed_X = absolute_accuracy_decay > 0`.
  Use only problems present in both the dump and the CSV. Exclude the row
  whose `permutation_type` is an aggregate (e.g. `OVERALL`), if any.
- **Score** = out-of-fold robustness margin from the exact v3 procedure:
  `self-perturb/scripts/evaluate.py` pipeline (StandardScaler → SelectKBest →
  balanced LogisticRegression, inner GridSearch over `GRID`), on columns
  87-112 only, outer `StratifiedKFold(5, shuffle=True, random_state=s)` on
  `model_is_robust` for s in 0..4; average each problem's held-out
  `decision_function` over the 5 seeds. Higher = more robust.
- Single features: `multidistract_cos_mean_d0.1`, `multidistract_cos_min_d0.1`,
  and controls `rename_poolcos_d0.25`, `typos_poolcos_d0.25`.
- AUC per type X: `roc_auc_score(failed_X, -value)` (higher = predicts failure).
- p per cell: 1000 shuffles of `failed_X` within that type, one-sided.

**Report schema** (`collab/reports/T-003.md`) — one row per type:

| type | n_problems | n_failed | AUC score | p | AUC cos_mean_d0.1 | AUC cos_min_d0.1 | AUC rename_poolcos | AUC typos_poolcos |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |

Plus: the script path (`self-perturb/scripts/specificity.py`) and the commit.
No interpretation needed; Claude reviews.
