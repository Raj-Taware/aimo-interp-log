# T-010 — Local leaderboard + feature dump on `aimo-interp/train-main-v2` (GPU ~30 min)

**Why.** The organizers released `aimo-interp/train-main-v2` (2026-09-17): 82
rows, 37 for the four small-track models, olympiad-length problems (median 47
words) — the competition's distribution, unlike the MATH set (16 words).
Claude checked (CPU): length alone has AUC **0.477** here (0.744 on MATH),
and on the 9 problems labelled for >= 2 small models the models **never**
disagree. So our MATH-trained signal is a length artifact that does not
transfer, and robustness looks problem-level. This task measures every
submission candidate on in-distribution data.

**Data.** HF `aimo-interp/train-main-v2`, split `train`. Columns `model_id`,
`reasoning_effort`, `problem`, `is_robust` (bool or null), `max_drop`.
Use the 37 rows whose `model_id` is a small-track checkpoint; the 34 with
non-null `is_robust` are scored, the 3 null rows are still run.

**Steps.**
1. **Local leaderboard.** For each ZIP in `self-perturb/results/submissions/`
   (`...-v2.zip`, `...-v3b.zip`) plus an always-True baseline: unzip, import
   its `solution.are_robust`, call it once per model with that model's
   problems (exactly as the grader batches). Score on the 34 labelled rows.
2. **Feature dump.** `dump_features.py` cannot read this schema; write
   `self-perturb/scripts/dump_trainv2.py` that calls
   `selfperturb.features.case_features` (repaired tokenizer) for each of the
   37 rows on that row's own model. Save one `.npz` per model with
   `features, labels (is_robust, NaN for null), max_drop, problems, columns`.
3. Canary per PROTOCOL rule 3 first (or cite a same-day canary).

**Report schema** (`collab/reports/T-010.md`):

| candidate | accuracy (of 34) | balanced acc | robust predicted | per-model accuracy (Qwen/Sky/Olmo/DS) |
| --- | ---: | ---: | ---: | --- |
| always-True | | | | |
| v2 ZIP | | | | |
| v3b ZIP | | | | |

Plus: dump paths, seconds per model, NaN count, commit. Outputs in
`self-perturb/results/grok/T-010/`. Board edits on `main`; Claude merges.

## Review (Claude, 2026-10-07): done

The set is 72% robust; the hidden test is balanced, so balanced accuracy is
the transferable number: always-True 0.500, **v2 0.475**, **v3b 0.692**
(catches 8/10 spurious). Row-level chance of v3b's hit rate p = 0.046, but
rows repeat problems (20 problems, labels agree across models): a
problem-level permutation of the v3 margin AUC (0.621) gives p = 0.132.
Per-model margin AUC: Qwen 0.81, DeepSeek 0.62, Olmo 0.57 (Skywork n=3).
Length AUC 0.477 here, margin-length r = +0.44 — v3b's in-distribution
signal is not length. Reading: weak, unconfirmed signal for v3b; none for
v2. Evidence favours nominating v3b over v2 for final ranking.
