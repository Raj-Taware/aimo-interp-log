# T-021 — Self-domain-rewrite white-box features (last mechanism-targeted test; Kaggle)

**Why.** `scripts/label_mechanism.py` (results/label_mechanism.json): 80 of the 101
official non-robust DeepSeek labels come from "domain" rewrites (problem recast as a
story by gpt-oss-120b), and 88% of those harmful rewrites lose a number of the original.
So the label is mostly "does a story rewrite of this problem break it". T-020's
rule-based variants had no domain type and failed the gate. This task lets the model
under test write its own domain rewrite and reads its internals on original vs rewrite.

**Environment:** the T-019 HF environment (transformers 5.13.0, fp16, 2x T4,
`selfperturb.features.load_model` / `build_prompt`). No vLLM needed.

**Steps.**
1. Canary (rule 3) as in T-019; stop if it differs.
2. Smoke: `python scripts/dump_selfdomain.py --model deepseek-ai/DeepSeek-R1-0528-Qwen3-8B --source data/math.parquet --out <run>/smoke --limit 5`.
   Paste the 5 printed rewrites into the report. If a rewrite is empty, still
   contains `<think>`, or is a solution instead of a problem, **stop and report**.
3. Full: same command, no `--limit`, `--out self-perturb/results/grok/T-021` (137 rows, ~30-45 min).
4. Commit `selfdomain__deepseek-ai_DeepSeek-R1-0528-Qwen3-8B.npz` + logs. **Do not analyse**
   and never submit to Codabench. Claude runs `scripts/eval_selfdomain.py`.

**Pre-registered test (Claude, before data; `eval_selfdomain.py`).** One candidate
W = all non-text columns. Pass iff L+W beats L by >= 0.03 balanced accuracy, wins
>= 60% of non-tied folds, sign p < 0.05. L+text (number retention) is reported as a control.
Fail -> no further white-box work; the paper leads with the label-mechanism finding.

**Budget:** ~1-1.5 Kaggle GPU h (inside the 14 h Raj approved for T-020; 4.1 h used).
**Deadline:** Thu 30 Oct 18:00 IST.

**Report** (`collab/reports/T-021.md`): canary, smoke rewrites, rows, s/row, GPU h, commit.
