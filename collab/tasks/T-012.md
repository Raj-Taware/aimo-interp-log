# T-012 — Phase 1 geometry dumps (GPU ~45 min)

**Why.** Adversarial review of v4: it compares unaligned summaries with raw
cosine before any reasoning, so it mostly measured problem length.
`self-perturb/src/selfperturb/geometry.py` replaces that with token-aligned
representational geometry (CKA, whitened cosine, answer-position cosine,
logit-lens KL, distractor excess-attention), per layer. This task produces
the data; Claude runs the pre-registered evaluation below.

**Runs** (from `self-perturb/`, env per rule 2; models load with eager attention):
```bash
python scripts/dump_geometry.py --kind math    --model deepseek-ai/DeepSeek-R1-0528-Qwen3-8B --out results/grok/T-012/dumps
python scripts/dump_geometry.py --kind trainv2 --model Qwen/Qwen3.5-4B                       --out results/grok/T-012/dumps
python scripts/dump_geometry.py --kind trainv2 --model Skywork/Skywork-OR1-Math-7B           --out results/grok/T-012/dumps
python scripts/dump_geometry.py --kind trainv2 --model allenai/Olmo-3-7B-Think               --out results/grok/T-012/dumps
python scripts/dump_geometry.py --kind trainv2 --model deepseek-ai/DeepSeek-R1-0528-Qwen3-8B --out results/grok/T-012/dumps
```
Before them: rule-3 canary. Also a determinism check: run the first 5 MATH
DeepSeek cases twice in one process (`case_geometry`), report max |diff|.

## Pre-registered evaluation (Claude, fixed before any data)

Data: MATH = 137 DeepSeek-labelled problems; TV2 = 34 labelled train-main-v2
rows (20 problems). TV2 significance by **problem-level** label permutation.

- **H1 mechanism, excess attention** (no fitting): `distract_attnx_mean`,
  higher = spurious. Pass: AUC(spurious) > 0.60 on TV2 with p < 0.05, and
  in the same direction on MATH after adding length (`L + attnx` beats `L`
  per the T-004 rule).
- **H2 mechanism, mid-depth geometry** (no fitting): mean of
  `distract_cka_d0.4/0.55/0.7`, lower = spurious. Same pass rule as H1.
- **H3 classifier**: the v4 procedure (SelectKBest + balanced LR, inner CV)
  trained on MATH geometry features, per-model standardization using each
  model's own TV2 batch (label-free), per-batch median decision on TV2.
  Pass: TV2 AUC > 0.675 (v4) with p < 0.05.
- Any pass on TV2 only, failing MATH-beyond-length, is reported as
  "in-distribution signal, mechanism unconfirmed".
