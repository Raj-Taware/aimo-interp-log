# T-019 — Question-only residual-stream dump (last white-box test beyond length; Kaggle)

**Why.** Claude re-ran the white-box ablation (2026-10-28,
`AIMO/scripts/ablate_whitebox.py`). On the 137 labelled DeepSeek MATH
problems every white-box block we have (v2 drift, T-013 CKA / wcos / lens /
attnx) is a length proxy: after residualizing on log(words, chars) all fall to
AUC 0.38-0.52, while length alone scores AUC 0.75 (reproduces T-004 / T-005).
The one untested white-box signal is the raw residual stream of the
*unperturbed* question (literature: question-only linear probes predict
answer correctness). This task dumps it; Claude runs the pre-registered test.

**Environment:** Kaggle T4x2, the v4 environment (transformers 5.13.0,
torch 2.12.1, fp16, repaired `load_tokenizer`), `selfperturb.features.load_model`
and `build_prompt` exactly as `dump_features.py` uses them (same chat
template, same system prompt, no generation).

**Steps.**
1. Canary (rule 3) on the T-008 canary rows; stop if features differ.
2. New script `self-perturb/scripts/dump_states.py --model <m> --source <parquet> --out <dir>`:
   one forward pass per problem with `output_hidden_states=True`; for
   layers `range(0, n_layers + 1, 4)` plus the last layer, store
   * `mean`: mean over the problem's prompt tokens (exclude padding), float16
   * `last`: the final prompt token's state, float16
   and per row `n_tokens`, `problem`, `label` (as in the source). Save
   `states.npz` with keys `mean [n, L, d]`, `last [n, L, d]`, `layers`,
   `n_tokens`, `problems`, `labels`, `model_id`.
3. Run it for:
   * DeepSeek on `data/math.parquet` (137 rows; source URL as in `make_kernel_t013.py`) — the labelled set
   * all 4 small models on `data/trainv2.parquet` (as in `make_kernel_t013.py`)
   * all 4 small models on `self-perturb/data/pool_unlabelled.parquet` (173 rows, labels dummy)
4. Commit to `self-perturb/results/grok/T-019/` (one npz per model x source).
   If a file exceeds 90 MB, split by layer.
5. **Do not submit to Codabench and do not analyse** — Claude runs the test.

**Pre-registered test (Claude, written before the data exists).** DeepSeek,
137 rows, nested CV as T-004 (5 seeds x 5 outer folds, balanced LR, inner CV
over C; PCA to 32 dims fitted inside each training fold). Per layer and
pooling, H = PCA states, L = log(words, chars):
the signal adds beyond length iff **L+H beats L by >= 0.03 mean balanced
accuracy and wins >= 60% of non-tied folds** for at least one layer x
pooling, with Holm correction over the layers tried. Fail -> the paper
reports "no white-box signal beyond length on the labelled set" as the
headline negative result and nothing new is submitted.
