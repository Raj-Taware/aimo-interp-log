# T-006 — Ground-truth answers for the 154 labelled problems (CPU)

**Why.** Prep for generating our own robust/spurious labels for all four
small models (pending Raj's H100 decision) and for an "immediate answer is
correct" probe. The organizers' labels condition on correctness
(`base_accuracy`), so ours need the true answers.

**Inputs.**
- 137 problems: `aimo-interp/augmented-sample-math-agg` (columns include
  `dataset_id` = `hendrycks-math-{train,test}-reference-*`, `problem_id`).
- 17 problems: `self-perturb/results/grok/T-002/extra_labels.parquet`.
- Answers: the public MATH dataset (Hendrycks et al.), e.g. HF
  `EleutherAI/hendrycks_math` (all subject configs, train + test).

**Steps.**
1. Match each of the 154 problem texts to MATH by exact text after whitespace
   normalization (collapse runs of whitespace, strip). If `problem_id` maps
   directly to a MATH record, use it as a cross-check, not the primary key.
2. Extract the answer from the MATH `solution`: the argument of the LAST
   `\boxed{...}` (or `\fbox{...}`), with balanced-brace parsing — no regex
   that stops at the first `}`.
3. Write `self-perturb/results/grok/T-006/answers.parquet`: `original_problem,
   source_set (agg|extra), problem_id, answer, subject, level, match`
   (`exact` | `normalized` | `none`).
4. Script: `self-perturb/scripts/fetch_answers.py`.

**Done when.** Every problem has a `match` value; unmatched ones listed.
