# T-002 — Recover more labelled DeepSeek problems and dump their features

**Why.** Training has 137 labelled DeepSeek problems. Two public per-type
tables hold more. Verified by Claude: the rule *robust iff max
`absolute_accuracy_decay` over that problem's rows <= 0* reproduces the
official `model_is_robust` on 128/128 and 52/52 overlapping problems. Expect
~26 new problems (17 + 9 before deduplication).

**Inputs.**
- labelled set: `aimo-interp/augmented-sample-math-agg` (HF, split `validation`)
- per-type A: `aimo-interp/augmented-sample-math-full-filtered` (HF, split `validation`)
- per-type B: `math-robust-final.csv` from https://github.com/aimo-interp/baselines (`data/`)
- all rows have `model_id == "qwen3-8b:low"` = `deepseek-ai/DeepSeek-R1-0528-Qwen3-8B`

**Steps.**
1. Write `self-perturb/scripts/build_extra_labels.py`: per-type A and B rows →
   group by `original_problem` → label = `max(absolute_accuracy_decay) <= 0`.
   Drop problems already in the labelled set. If A and B both contain a
   problem with different labels, drop it and list it.
2. Output `self-perturb/results/grok/T-002/extra_labels.parquet` with columns
   `original_problem, model_id ("qwen3-8b:low"), model_is_robust, source,
   max_decay, types_present`.
3. Canary (PROTOCOL rule 3) — or cite T-001's report if already done.
4. Dump v3 features with the existing script, from `self-perturb/`:
   ```bash
   python scripts/dump_features.py --model deepseek-ai/DeepSeek-R1-0528-Qwen3-8B --source results/grok/T-002/extra_labels.parquet --out results/grok/T-002/dumps
   ```
   then the same for `Qwen/Qwen3.5-4B`, `Skywork/Skywork-OR1-Math-7B`,
   `allenai/Olmo-3-7B-Think`, each with
   `--problems-of deepseek-ai/DeepSeek-R1-0528-Qwen3-8B`.

**Done when.** Four `.npz` dumps, each `nan_or_inf == 0` and the same case count.
