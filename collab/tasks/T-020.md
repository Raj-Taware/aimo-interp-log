# T-020 — Self-made DeepSeek labels on MATH train (3x the labelled set; Kaggle, vLLM)

**Why.** T-019's pre-registered test failed (`self-perturb/results/grok/T-019/eval/`):
question-only states add nothing beyond length on the 137 labelled problems,
and a 52-variant exploratory sweep (Claude, 2026-10-28) found only isolated
+0.05-0.06 gains that do not survive Holm. With 137 labels fold noise is
about +-0.08 balanced accuracy, so a real +0.03 signal is invisible. The
rules allow extra labelled data. The organisers' labels come from
`hendrycks-math-train-reference-500` (MATH train, types distract / rename /
rephrase / typos, rule robust iff max decay <= 0), so we can make more of
the same kind cheaply: gold answers come with MATH, so there is no gold stage
(T-016's 11 h sink), and MATH traces are short.

Raj chose this route on 2026-10-28. **Budget: about 10-14 Kaggle GPU h in
total. Raj must confirm the budget to Grok before Phase 2** (it goes past
the 15 h/week cap from T-016).

**Inputs (committed by Claude, `self-perturb/results/grok/T-020/`):**
* `problems_gate.jsonl` (40): organisers' labelled DeepSeek problems found verbatim
  in MATH train (12 robust), with `official_label`
* `problems_new.jsonl` (161): MATH train problems in no organiser table, at the
  labelled set's level mix
* `problems.jsonl` (both), `stage2_variants.jsonl` (rule-based, `rule_variants.py`;
  no LLM writer needed)
* made with `scripts/label_gen/fetch_math.py` (seed 0) — do not regenerate

**Environment:** the T-016 vLLM setup (vLLM 0.31.0, transformers 5.13.0,
TRITON_ATTN on T4, torchaudio uninstalled), DeepSeek-R1-0528-Qwen3-8B with
`--tensor-parallel-size 2`, fp16. Only DeepSeek: the probe is trained on DeepSeek labels.

**Phase 1 — gate (~2 GPU h).** Use `R=<run>/gate` and `P=results/grok/T-020/problems_gate.jsonl`:
```bash
M=deepseek-ai/DeepSeek-R1-0528-Qwen3-8B; V=results/grok/T-020/stage2_variants.jsonl
python scripts/label_gen/stage1_solve.py --backend vllm --tensor-parallel-size 2 --model $M \
    --problems $P --out $R --samples 5 --max-new-tokens 6144 --min-base-acc 0.5
python scripts/label_gen/stage3_solve_variants.py --backend vllm --tensor-parallel-size 2 --model $M \
    --problems $P --stage1 $R/stage1_summary.jsonl --variants $V --out $R \
    --samples 4 --max-new-tokens 6144 --types distract rename rephrase typos \
    --source "self-labelled (T-020 MATH rule variants)"
python scripts/label_gen/math_gate.py --problems results/grok/T-020/problems.jsonl \
    --variants $V --labels $R/labels.jsonl --out $R
```
Commit `stage1_summary.jsonl`, `labels.jsonl`, `gate_report.json`, and the token stats
(median tokens, hit-cap count, tok/s) right away.

**Pre-registered gate (Claude, before data):** pass iff, under rule A on
complete gate rows, **agreement >= 0.70 AND kappa >= 0.30** (`gate_report.json` `pass`).
* fail -> **stop**, report, do not run Phase 2.
* pass -> Phase 2 (once Raj has confirmed the budget).

**Phase 2 — new labels (~8-12 GPU h).** Same commands with `R=<run>/new`,
`P=results/grok/T-020/problems_new.jsonl`. If two T4x2 sessions are free,

safe), then merge the `labels.jsonl` files. Then run `math_gate.py` on the
merged labels (gate + new). It writes `labels_new.parquet` (agg schema,
model_id DeepSeek).

**Phase 3 — dumps (~40 min).** On `labels_new.parquet`, DeepSeek, exactly as in T-002 / T-019:

* `scripts/dump_states.py` (question-only states)

Commit to `self-perturb/results/grok/T-020/{gate,new,dumps,states}/`.
