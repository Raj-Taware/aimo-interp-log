# T-001 — Canary: does Grok's GPU reproduce the reference features?

**Why.** Our features are differences at fp16 rounding scale. The classifier
was trained on Kaggle-T4 features; if Grok's GPU computes them differently,
every later Grok dump needs to be interpreted with that in mind.

**Steps.**
1. Env per PROTOCOL rule 2. Work from `self-perturb/` (put `src/` on `sys.path`).
2. For each line of `collab/canary.jsonl`:
   `selfperturb.features.case_features(tokenizer, model, problem)` with
   `tokenizer, model = selfperturb.features.load_model("deepseek-ai/DeepSeek-R1-0528-Qwen3-8B")`.
3. Compare each 113-vector with row `dump_row` of
   `self-perturb/results/feature-dumps/2026-09-29_v3-features_tf5.13_unbatched-fp16/deepseek-ai_DeepSeek-R1-0528-Qwen3-8B.npz`
   (`features[dump_row]`).
4. Run step 2 a second time in the same process (determinism).
5. Commit the script as `self-perturb/scripts/canary.py` and the raw vectors as
   `self-perturb/results/grok/T-001/canary_features.npz`.
