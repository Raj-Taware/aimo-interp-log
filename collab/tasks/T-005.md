# T-005 — Three candidate signals beyond length (pre-registered, CPU)

**Why.** T-004: drift adds nothing beyond problem length (L alone AUC 0.746;
L+R won 0/25 folds). Three untested signals already sit in the dumps. Each is
either not drift, or cancels length by construction rather than by
regression.

**Candidates** (DeepSeek, v3.1 unbatched-fp16 dump, 137 problems):
- `X1` answer-shift: `{rename,numerals,typos,distract,rephrase,number_jitter}_kl`,
  `multidistract_kl_mean`, `multidistract_kl_max` — does an edit change the
  model's immediate answer guess (KL at the `\boxed{` position)?
- `X2` answer confidence: `base_entropy`, `base_top1`, `base_margin` — how
  sure the model is of its first answer token before any reasoning.
- `X3` length-cancelling drift ratios, with `g(c) = log(1 - c + 1e-6)`:
  - `g(multidistract_cos_mean_d0.25) - g(rephrase_cos_d0.25)`
  - `g(multidistract_poolcos_mean_d0.25) - g(rephrase_poolcos_d0.25)`
  - `g(typos_cos_d0.25) - g(rephrase_cos_d0.25)`
  Rephrase only wraps the statement in neutral framing, so its drift is a
  per-problem baseline that scales with length like the others.

`L` = [log n_tokens, log n_words] as in T-004.

**Model.** No feature selection (sets are small): StandardScaler → balanced
LogisticRegression, inner 4-fold CV over C in {0.01, 0.1, 1}; outer
`StratifiedKFold(5, shuffle=True, random_state=s)`, s = 0..4. Same splits for
every set so folds pair up.

**Pre-registered criterion, per candidate** (3 candidates, so treat a lone
marginal pass with caution): `L+X` beats `L` by >= 0.02 mean balanced accuracy
AND wins >= 60% of non-tied folds. Report all three either way.
