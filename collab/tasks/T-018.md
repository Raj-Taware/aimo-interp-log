# T-018 — v4 features on the 173 unlabelled AIME/AMC problems (v4b thresholds; Kaggle)

**Why.** Discord 2026-10-16: the grader now calls `are_robust` **once per
problem, each in a fresh process**. v3b/v4 split a batch at its median, which
never fires with one problem, so v4 falls back to a zero threshold that is
near all-True on competition-length text (Qwen v4 margins on train-main-v2
are all > 0). v4b sets each model's threshold to its median margin over
unlabelled competition-like problems. Labels are never used.

**Steps (Kaggle T4x2; the v4 environment: transformers 5.13.0,
torch 2.12.1, fp16; repaired `load_tokenizer`):**
1. Canary (rule 3) on the T-008 canary rows; stop if features differ.
2. For each of the 4 small models:
   `python scripts/dump_features.py --model <m> --source data/pool_unlabelled.parquet --out results/grok/T-018/features`
   (173 rows per model; `model_is_robust` in that parquet is a dummy).
3. `python scripts/set_thresholds.py --features results/grok/T-018/features --artifacts results/artifacts-v4 --out results/grok/T-018/artifacts-v4b`
4. Commit `features/*.npz`, `artifacts-v4b/`, and paste `thresholds.json`
   into the report. **Do not submit to Codabench** — Claude builds and checks
   the v4b bundle, Raj decides on submission.

Can run in the same kernel as T-017 (both forward-pass only). Budget ~1-2
Kaggle h; ask Raj first if this week's total would pass 15 h.
