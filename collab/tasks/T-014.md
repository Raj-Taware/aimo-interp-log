# T-014 — Build the olympiad self-labelling pipeline; dry-run on Kaggle

**Why.** Raj approved the H100 run (2026-10-08). Purpose: a competition-like
labelled set large enough to (a) confirm or reject H1 (excess attention,
T-012: TV2 AUC 0.79, p = 0.019) and (b) choose the final nomination. Every
H100 minute must be execution, so the pipeline is built and dry-run first.
Plan: `collab/plans/H100-labels.md` (this task supersedes its problem source).

**Problems.** HF `AI-MO/aimo-validation-aime` (90) + `AI-MO/aimo-validation-amc`
(83): integer answers, olympiad level. Record problem id, text, answer.

**Pipeline** (`self-perturb/scripts/label_gen/`, vLLM on H100; must also run
with plain transformers for the dry run):
1. `stage1_solve.py` — each small model, each original problem: 4 samples,
   T-009 protocol (repaired `load_tokenizer`, boxed instruction, sampling
   from `generation_config`, no eos override, extraction boxed -> bold ->
   "answer is"), max 12288 new tokens. Output per (model, problem):
   `base_acc`, tokens, raw text. Keep pairs with `base_acc >= 0.5`.
2. `stage2_variants.py` — `openai/gpt-oss-120b` writes one variant per type
   (domain, distract, rephrase, rename, typos) for each problem kept by any
   model. Prompt states the type and the answer, and requires the answer be
   unchanged. Save variants; spot-check file of 20 random variants for
   Claude.
3. `stage3_solve_variants.py` — each kept (model, problem): 2 samples per
   variant -> `perm_acc` per type; `max_drop = base_acc - min(perm_acc)`;
   label robust iff `max_drop <= 0.10`, spurious iff `>= 0.25`, else null
   (the organizers' rule, train-main-v2 README).
4. Resumable everywhere (append-only jsonl, skip done keys) — H100 time
   comes in 5-hour slots.

**Dry run (Kaggle T4x2, transformers generate, no vLLM).** 3 AIME + 3 AMC
problems, Skywork only, max 4096 tokens, 2 samples; stage 2 with a small
stand-in writer (Skywork itself) since gpt-oss-120b does not fit a T4. Goal:
every stage runs end to end and resumes after a kill.

**Report schema** (`collab/reports/T-014.md`):

| stage | ran end to end | resumed after kill | outputs | notes |
| --- | --- | --- | --- | --- |
