# T-004 — Does drift carry signal beyond problem length? (pre-registered, CPU)

**Why.** Claude found (verify as step 0): word count alone predicts DeepSeek's
robust label with AUC 0.744, above our method's 0.68, and
`multidistract_cos_mean_d0.1` correlates Spearman +0.83 with word count. A
fixed inserted sentence moves a long problem's state less. So much of the
v3 signal may be a length proxy. This task tests what is left after length.

**Pre-registered success criterion (fixed before results).** Residualized
drift adds signal beyond length if BOTH hold on DeepSeek nested CV:
(a) `L+R` beats `L` in balanced accuracy by >= 0.03 (mean over the 25 outer
folds) and wins in >= 60% of folds; (b) `R` alone has AUC >= 0.55.
Report the outcome either way.

**Inputs.** The four v3 unbatched-fp16 dumps in
`self-perturb/results/feature-dumps/2026-09-29_v3-features_tf5.13_unbatched-fp16/`
(DeepSeek is labelled; the other three share its problems, labels borrowed).
Tokenizers only — no model weights, no GPU.

**Definitions.**
- Length, per problem and model: `n_words` (whitespace split), `n_chars`,
  `n_tokens` (that model's tokenizer on the raw problem text).
- `L` = [log n_tokens, log n_words].
- `D` = columns 87-112 (v3 block).
- `R` = residualized `D`, **label-free, per model**: for each column j, fit OLS
  `D_j ~ a + b * log(n_tokens)` on all 137 problems of that model's dump
  (no labels used); `R_j = D_j - fitted`.
- Evaluate with `self-perturb/scripts/evaluate.py`'s `nested_cv` (balanced
  class weight, same GRID, seeds 0-4). Add an option returning per-fold
  balanced accuracies so sets can be compared fold by fold on identical splits.

**Steps.**
0. Reproduce Claude's two numbers above (AUC of `n_words` vs label; Spearman
   of `n_words` vs `multidistract_cos_mean_d0.1`).
1. Nested CV on DeepSeek for: `L`, `D`, `R`, `L+D`, `L+R`.
2. Paired fold comparison `L+R` vs `L`: mean difference, % folds `L+R` wins.
3. T-003 table again, using the OOF score of `R` (and of `L+R`), plus the
   single residual feature `R[multidistract_cos_mean_d0.1]`.
4. Cross-model proxy: train `R` on DeepSeek, compute each other model's `R`
   with its own fit, report AUC vs DeepSeek labels. Same for `L`.
5. Script: `self-perturb/scripts/length_control.py`; outputs in
   `self-perturb/results/grok/T-004/`.

## Review (Claude, 2026-10-01): done — criterion failed (negative result)

Reproduced independently with a word-based residual: L 0.683 / AUC 0.750,
R 0.386 / AUC 0.316 (below chance = typical CV behaviour with no signal),
L+R 0.627 / 0.683. Grok's `evaluate.py` change only adds `return_folds`;
means are unchanged when every fold has both classes. Conclusion: on public
DeepSeek data, self-perturbation drift is essentially a problem-length proxy.
