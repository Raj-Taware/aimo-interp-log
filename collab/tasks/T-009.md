# T-009 — Generation smoke v2: fix the protocol, then re-measure (GPU)

**Why.** T-007's numbers were mostly protocol artifacts, not model behaviour
(Claude's review in `collab/tasks/T-007.md`). Do T-008 first.

**Changes from T-007.**
1. Tokenizer: `selfperturb.features.load_tokenizer` (repairs DeepSeek).
2. Prompt: user turn = problem + `"\n\nPlease reason step by step, and put your final answer within \\boxed{}."`
3. Sampling: take `temperature`, `top_p`, `top_k` from `model.generation_config`
   when set, else 0.6 / 0.95 / none. Do NOT pass `eos_token_id`; let
   `generation_config` supply the stop tokens. Record the values used.
4. Extraction: last `\boxed{}`; else the last `**...**` span; else the last
   number after "answer is". Record which rule fired.
5. Memory: batch size 2 (Olmo: 1). Still 8192 max new tokens, 30-min cap per model.
6. Problems: the first 6 of T-007's `problems.json`.

**Report schema** (`collab/reports/T-009.md`) — one row per model:

| model | sampling used | median tokens | % hit cap | % stopped | correct (of 6) | extraction rule counts | looping outputs (count) | tok/s |
| --- | --- | ---: | ---: | ---: | ---: | --- | ---: | ---: |

"Looping" = the last 4000 characters repeat a 40-character chunk at least 4
times. Raw outputs in `self-perturb/results/grok/T-009/generations.jsonl`.
